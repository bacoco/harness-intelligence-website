L'édition signée doit arriver jusqu'au posteHermes transmet le commit approuvé à l'installation catalogueThe approved edition must be the one sent to the stationHermes carries the approved commit into catalog installation

Le bon signé indique l'édition choisie, et cette indication accompagne sa mise en place au poste. Une pile déjà présente n'est réutilisée que si son étiquette correspond ; cela ne certifie pas chaque page à l'intérieur.Le commit approuvé est transmis à l'installateur ; un arbre existant aux métadonnées catalog SHA différentes n'est pas réutilisé. Ce contrôle compare des métadonnées et ne constitue pas une attestation cryptographique des octets disque.The signed slip's chosen edition travels with the work of putting it at the station. An existing stack is reused only when its label matches, which does not independently certify every page inside.The reviewed patch forwards the approved commit and rejects reuse when stored catalog-SHA metadata disagrees. Matching metadata binds the declared revision but is not cryptographic attestation of the local bytes.

Après un nouvel essai, lire son propre reçuMécanismeAfter another attempt, read that attempt's own receiptMechanism

Après une nouvelle tentative, le reçu doit dire si le poste est ouvert, quels ustensiles sont là et ce qu'il reste à préparer. Une ancienne fiche de recherche portant le même numéro ne raconte pas ce nouvel essai.La carte de retry est reconstruite depuis son résultat réel : enabled, outils et setup manquant. Une carte de search antérieure partageant le callID ne sert plus de substitut au résultat d'installation.The new attempt's receipt says whether the station is open for work, which utensils are available and which preparations are still missing. An earlier catalogue slip with the same number cannot tell that story.Retry UI derives from the actual returned installation result, including enabled state, tools and remaining setup. Sharing a callID with a previous search card does not make that card evidence of the new attempt.
