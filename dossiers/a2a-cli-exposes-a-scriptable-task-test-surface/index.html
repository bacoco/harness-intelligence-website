Le comptoir annonce plusieurs façons de transmettre les billets. Le chef peut préparer le même contrôle sans demander à un autre commis d'en deviner le résultat. Cela ne prouve pas encore que tous les cuisiniers comprennent chaque trajet.Le client écrit en Go vise JSON-RPC, REST et gRPC. Ses sorties JSON et codes de sortie permettent de confronter les scripts aux résultats du protocole. Le support annoncé n'est pas une certification de tous les agents, endpoints ou transports.Several routes are advertised for carrying an order, while the test counter produces records a checker can inspect. That makes a test surface available in principle. It does not establish that every receiving kitchen handles every route correctly.A scriptable client can separate test orchestration from agent reasoning. Its existence does not validate endpoint behavior, transport parity or task semantics by itself. Those claims require observed exchanges and bounded test coverage, absent here.
