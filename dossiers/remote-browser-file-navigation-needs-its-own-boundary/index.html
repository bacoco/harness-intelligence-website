Le chef borne les placards de sa cuisine, mais le commis peut lire ceux d'une autre maison. Un changement accepté permet d'interdire cette catégorie de visite ; elle reste permise par défaut.file-navigations=false refuse file: dans new_page, navigate_page et slim navigate ; le défaut demeure true. La garde par schéma évite d'assimiler les MCP roots du serveur au filesystem d'un navigateur distant.A rule around this kitchen's cupboard cannot define the files in another kitchen's cupboard. The accepted change offers an explicit way to block those visits, while keeping them allowed by default.The new flag gates file-scheme navigation at the browser-tool boundary rather than validating a path against the MCP server's local roots. The restriction requires explicit configuration; file navigation remains enabled by default.
