Des brigades rangent leurs fiches dans un tiroir caché derrière un autre. La mise en place du matin ne va jamais les chercher. Un geste spécial les récupère pendant un temps. Quand l’ouverture de la maison change, ce geste revient les mains vides.Les skills imbriqués n’étaient pas découverts, ce qui a poussé les utilisateurs à les exposer par des hooks de démarrage. Une évolution ultérieure du démarrage a cassé ce contournement alors que les fichiers de skills n’avaient pas changé. La découverte se comporte donc comme une interface versionnée du harnais, jamais documentée comme telle.Some brigades keep their cards in a drawer hidden behind another. Morning preparation never reaches them. A special opening move retrieves them for a while. When the house changes its opening routine, that move returns empty-handed.A startup-hook workaround stopped working although no skill file had changed. The workaround existed because nested skills were never picked up by runtime discovery, and it broke when a later release altered startup behaviour. Discovery plus initialisation order therefore acts as a versioned interface, documented or not.

La brigade pensait qu’une fiche rangée serait forcément disponible. En réalité, tout dépendait de l’ordre secret dans lequel les tiroirs étaient ouverts le matin. Ce parcours n’était écrit nulle part.L’interface effective n’était pas le fichier SKILL.md mais l’algorithme de découverte associé à l’ordre d’initialisation. Les utilisateurs dépendaient donc d’une API non documentée, sans contrat ni garantie de compatibilité.The brigade assumed that a stored card would always be available. In fact, everything depended on the secret order used to open drawers each morning. That route was never written down.The effective contract was never SKILL.md; it was the discovery algorithm combined with initialisation order. Depending on it meant depending on an undocumented API that carried no compatibility guarantee.
