Les vieux billets et les nouveaux n'ont pas la même vérificationMécanismeOld jobs and new arrivals need different checksMechanism

Retrouver les billets déjà écrits ne prouve pas que le prochain billet passe. Voir l'ustensile de rappel ne prouve pas non plus qu'il soit permis à chaque poste. Ces trois questions doivent être vérifiées séparément, même si la maison les annonce le même jour.La migration conserve les tâches ; la matrice de modes borne les capacités ; le correctif de file traite une transition répétée stop/resume/stop. La release ne suffit pas à établir les mécanismes internes ni une relation causale entre ces trois propriétés. Aucun lien avec un autre scheduler n'est démontré.A moved desk can retain old jobs while still mishandling the next arrival. A visible reminder utensil also says nothing about which station may use it. Preservation, availability and queue recovery are different questions, despite appearing in one announcement.Use separate acceptance criteria for retained tasks, effective per-mode tool availability and post-transition message handling. These are design checks derived from the release account, not tests performed here. Tool presence alone cannot certify either migration or recovery.
