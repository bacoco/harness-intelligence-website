Une étiquette chore ou l'absence de fichiers frontend ne suffit pas à les rendre non fonctionnels.The new review rule asks for pictures from a kitchen actually running and a before-and-after when service changes. Work in the back still counts, even if someone labels it ordinary tidying.Functional changes require evidence from a running Canvas and a before/after comparison, including backend changes. Declared chore status and frontend-path absence cannot determine the actual behavioral scope by themselves.
