La règle pour ce soir-là doit exister avant de lui donner ce pouvoir.Dès qu’un hook peut opposer un veto, le harnais doit définir le comportement lorsque le mécanisme de veto est indisponible. L’enforcement ajoute une panne de second ordre : celle du garde lui-même, distincte de l’action qu’il devait contrôler.While the clerk only wrote notes, his absence left a blank page. The rule for that night must exist before he receives that power.Once a hook can veto an action, the harness owes a defined behavior for the case where the veto mechanism is unavailable. Enforcement adds a second-order failure mode — the guard’s own failure, which is not the same event as the action it was meant to gate.
