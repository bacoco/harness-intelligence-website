Une ancienne liste ne rend pas une clé retirée valableRéponseYesterday's list cannot restore revoked accessResponse

Une autre règle, encore proposée, refuse de remplacer un accès refusé par une liste vide ou un vieux carnet. L'ancien carnet ne servirait que pendant une panne passagère ; sans carnet, cette panne reste une erreur.La PR registre encore ouverte propagerait l'échec d'authentification même avec cache chaud. Le stale resterait réservé aux pannes transitoires ; une panne sans cache serait propagée plutôt que convertie en succès vide.The separate open proposal keeps refused access visible instead of returning an empty list or an old one. An older list would be usable only during temporary trouble; with no saved list, that trouble remains an error.Authentication failure and transient unavailability receive different fallback semantics. The proposal does not allow stale cache to conceal a revoked registry credential, and it is not established as merged.
