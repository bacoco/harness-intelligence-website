Plusieurs commis se disputent le même billotL’allocation de worktrees est entrée dans le chemin d’exécution, à titre expérimentalSeveral cooks collide on one shared benchWorktree allocation entered the execution path, as an experimental feature

Avec un seul commis, le billot commun ne gêne personne. À plusieurs, les préparations commencent à se mélanger. La maison essaie donc un billot par commis. Cette organisation n’est pas encore utilisée partout.L’allocation gérée de worktrees est entrée dans le chemin d’exécution des sessions CLI. L’isolation du workspace devient ainsi une capacité de première classe du harnais plutôt qu’une convention appliquée par l’utilisateur. La fonctionnalité est explicitement expérimentale ; rien n’établit qu’elle soit devenue le comportement par défaut.One cook has no trouble with a shared bench. With several cooks, preparations begin to collide. The house is therefore trying one bench per cook. Not every service uses it yet.Managed worktree allocation moved into the execution path of CLI sessions. Workspace isolation thereby becomes a harness capability rather than a convention users are expected to apply themselves. The feature is explicitly experimental, and nothing establishes it as the default.
