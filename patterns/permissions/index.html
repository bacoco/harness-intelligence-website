Un billet à signer mettait en avant le geste le plus anodin d’une demande composée. Le geste qui engageait vraiment la maison restait caché derrière. Une première correction avait mieux séparé les gestes et renforcé les refus, puis le même défaut d’affichage est revenu.Sur des commandes shell composées, le prompt de permission de Claude Code pouvait mettre en avant un changement de répertoire anodin tandis que l’opération Git significative restait masquée derrière. L’utilisateur validait un libellé sans rapport avec l’autorité réellement accordée. Un correctif structurel a amélioré la segmentation et la priorité des règles de refus ; une récidive côté affichage a suivi. Cette récidive établit que la correction du parsing et la sémantique d’approbation sont deux problèmes distincts.A signing slip highlighted the most harmless move in a combined request. One correction separated the moves better and strengthened refusals, then the same display fault returned.On composed shell commands, Claude Code’s permission prompt could foreground an innocuous directory change while the meaningful Git operation stayed hidden behind it. La maison doit montrer l’autorité qu’elle demande réellement.Approuver la mauvaise description n’est pas une approbation éclairée.
