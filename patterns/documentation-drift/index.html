Des fiches sont passées d’un essai demandé à une règle servie d’office. Le classeur a gardé l’ancien mot pour aider les cuisines restées à l’ancienne saison. Il enseignait donc un service qui n’était plus celui du jour.La dérive de documentation apparaît lorsque la documentation publiée ne reflète plus le comportement ou les valeurs par défaut effectifs. Chez Gemini CLI, les skills sont passés d’un mode expérimental opt-in à un comportement activé par défaut, et les noms de configuration d’une sémantique expérimentale à une sémantique stable. Documentation et interface ont conservé le vocabulaire antérieur, volontairement, pour ne pas casser les utilisateurs d’anciennes versions.Some cards moved from a trial you requested to a rule served by default. The binder kept the older word to help kitchens on an earlier season. It therefore taught a service that was no longer today’s.Documentation drift appears when published documentation no longer reflects effective behavior or defaults. At Gemini CLI, skills moved from experimental opt-in to on-by-default, and configuration names moved from experimental to stable semantics. Documentation and UI deliberately kept the earlier vocabulary so that users on older versions would not break.
