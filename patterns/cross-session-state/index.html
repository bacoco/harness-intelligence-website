Un soir, une brigade a punaisé une note : « ne touchez qu’à cette étagère ». Après le service, elle est restée au mur. Le lendemain, une autre brigade l’a lue et l’étagère ne désignait déjà plus la même chose.L’état inter-session devient dangereux lorsqu’une donnée supposée locale persiste ou s’applique au-delà de la session qui l’a créée. Sur gstack, un verrou de périmètre de débogage stockait une frontière relative dans un état global à la machine sans la supprimer ; la même valeur persistée changeait de sens avec le répertoire de travail suivant et contraignait des sessions ultérieures sans rapport.One evening, a brigade pinned up a note: touch only that shelf. After service, it stayed on the wall. Next morning, another brigade read it and the shelf already meant something else.Cross-session state turns hazardous when data assumed local outlives or reaches past the session that created it. In gstack a debugging scope lock wrote a relative boundary into machine-global state and never removed it, so one persisted value changed meaning with the next working directory and constrained later, unrelated sessions.
