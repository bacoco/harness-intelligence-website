Le bon n’est pas seulement destiné aux yeux : il répartit le travail. Si une ligne choisit le commis ou l’ustensile, l’effacer retire ce choix, même si la nouvelle feuille paraît impeccable.Dans un système d’agents, le schéma visible par le modèle est une surface exécutable et non un format d’affichage. Retirer un champ retire donc, avec l’information, la décision que le modèle prenait à partir d’elle. La tromperie tient à ce que le changement se justifie par la confidentialité et la simplification, deux motifs corrects, dont la collision avec le contrôle de la délégation n’apparaît dans aucun test de format.The ticket is not merely for reading; it assigns work. If a line chooses the cook or utensil, erasing it removes that choice even when the new sheet looks perfect.In an agent system the model-visible schema is an executable surface, not a display format. Removing a field therefore removes, along with the information, the decision the model was making from it. The deception is that the change is justified by privacy and simplification — two sound motives — whose collision with delegation control appears in no format test.

Pour chaque ligne, le chef note le commis qui la lit et la décision qu’elle permet. Après le changement, il fait préparer une vraie commande et vérifie le poste, l’ustensile et la table obtenus. Une belle feuille seule ne prouve rien.Traiter les schémas visibles par le modèle comme des API : tout retrait de champ est un diff de capacité, pas un changement de présentation. Cette classe de changement demande des tests d’intégration exerçant la délégation de bout en bout, et non des tests de snapshot ou de format, qui restent verts par construction.For each line, the chef records which cook reads it and which choice it enables. After the change, a real order checks the resulting station, utensil, and table. A pretty sheet alone proves nothing.Treat model-visible schemas as APIs: any field removal is a capability diff, not a presentation change. This class of change calls for integration tests exercising delegation end to end, rather than snapshot or format tests, which stay green by construction.
