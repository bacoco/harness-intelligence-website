La première réparation améliore réellement le service, puis le même type de désordre réapparaît par une autre porte. Dans un cas, la fiche verte oubliait encore un détail du poste. Dans l’autre, plusieurs passages ont été nécessaires avant que le stock cesse vraiment de grossir.Le signal est la récidive d’un défaut déjà traité, sous une variante structurellement voisine plutôt qu’identique. Chez gstack, un faux vert corrigé une fois est réapparu via une autre dimension d’identité, l’état de santé en cache étant réutilisé entre des contextes qui différaient sur ce qui déterminait réellement le succès de l’exécution. Chez Codex, la réduction de volume a demandé plusieurs vagues, la première n’ayant pas contenu la charge.The first repair genuinely improves service, then the same kind of mess returns through another door. In one case, the green card still missed a station detail. In the other, several rounds were needed before the stock truly stopped growing.The signal is recurrence of an already-treated defect, in a structurally adjacent variant rather than an identical one. At gstack a false green fixed once returned through another identity dimension, the cached health state being reused across contexts that differed on what actually determined execution success. At Codex volume reduction took several waves, the first having failed to contain the load.

Le garde reconnaît la caisse avant qu’elle change de nomMécanismeThe guard recognises the crate before its label changesMechanism

La brigade installe naturellement le garde à l’endroit où elle a découvert la faute. Mais la caisse peut encore être reconditionnée plus loin. Quand elle atteint le stockage sous un autre nom, la première barrière ne la reconnaît plus.Le premier modèle mental suppose que l’identité observée près de l’ingestion est celle qui atteindra l’effet final. Une transformation intermédiaire peut modifier cette classification, si bien qu’un filtre amont correct manque quand même l’écriture finale. La tromperie est que le premier correctif est réellement efficace sur ce qu’il mesure : le volume baisse, le vert revient, et la frontière fautive n’a pas été touchée.The brigade naturally posts the guard where the fault was first seen. But the crate may be repacked farther along. When it reaches storage under another name, the first barrier no longer recognises it.The first mental model assumes the identity observed near ingestion is the one that will reach the final effect. An intermediate transformation can change that classification, so a correct upstream filter still misses the final write. The deception is that the first fix genuinely works on what it measures: volume drops, green returns, and the faulty boundary was never touched.

Placer le garde juste avant le rangement définitifRéponsePlace the guard just before final storageResponse

Après une récidive, le chef déplace le contrôle vers la dernière porte, avant que la caisse soit rangée sans retour. Il lie aussi la fiche verte au fourneau, aux clés et au fournisseur réellement utilisés. Tout détail omis peut produire le prochain faux feu vert.Quand un correctif échoue deux fois, cesser de patcher la représentation vue en premier et déplacer le garde là où l’effet irréversible se produit, chez Codex le sink de persistance. Indexer de même un état de santé sur les dimensions d’identité qui déterminent l’exécution réelle : exécutable, contexte d’authentification, workspace ou provider selon le cas, comme l’a fait le second correctif chez gstack. Toute dimension exclue de cette clé reste une source possible de faux vert.After the fault returns, the chef moves the check to the last door before the crate is stored for good. The green card is also tied to the actual stove, keys, and supplier. Any omitted detail may produce the next false all-clear.When a fix fails twice, stop patching the representation seen first and move the guard to where the irreversible effect happens, at Codex the persistence sink. Index health state likewise on the identity dimensions that determine real execution: executable, authentication context, workspace or provider as applicable, as the second gstack fix did. Any dimension left out of that key remains a possible source of false green.

Une réparation traverse cinq portes avant d’être prouvéeLeçonA repair crosses five doors before it is provenLesson

Le retour de la panne révèle la mauvaise porte choisie la première fois. Ensuite, le chef distingue cinq étapes : correction écrite, acceptée, publiée, installée dans la cuisine et enfin observée pendant un vrai service.Un second correctif est une preuve causale : l’échec d’une première réparation incomplète localise le mécanisme ou la frontière réellement fautive. Il n’autorise pas pour autant à confondre les états de livraison — correctif source, code mergé, release, artefact installé, récupération observée — que plusieurs lineages indépendantes chez Codex, Archon, Claude Code et Gemini CLI ont montrés distincts.The fault returning reveals which door was wrongly chosen the first time. The chef then separates five stages: repair written, accepted, published, installed in the kitchen, and finally observed during real service.A second fix is causal evidence: the failure of an incomplete first repair locates the mechanism or boundary actually at fault. It does not license collapsing delivery states — source fix, merged code, release, installed artifact, observed recovery — which independent lineages at Codex, Archon, Claude Code and Gemini CLI showed to be distinct.
