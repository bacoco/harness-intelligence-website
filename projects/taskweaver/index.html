Un mot sur la porte n’écrit pas la causeMécanismeA note on the door does not write the causeMechanism

Une cuisine peut ralentir puis fermer. Les jours calmes ne disent pas pourquoi. Ici, le mot sur la porte est venu avant le rideau, mais il ne prouve pas la cause. C’est dans ce vide que les belles histoires s’inventent.La mortalité d’un projet est en général une transition orientée, pas un instantané à zéro commit : une métrique d’activité agrège des états causaux distincts et produit autant de faux morts que de fausses vies. Sur ce cas, le signal de ressources limitées est corrélé à l’archivage sans l’expliquer. Les analystes comblent naturellement les trous causaux avec des récits plausibles, et c’est exactement là qu’un état unknown explicite est requis.A kitchen can slow and then close. Quiet days do not say why. Here, the note on the door came before the shutter, but it does not prove the cause. Fine stories get invented in that gap.Project mortality is usually a directional transition, not a zero-commit snapshot: an activity metric aggregates distinct causal states and yields false deaths as readily as false lives. In this case the limited-resources signal correlates with the archive without explaining it. Analysts naturally fill causal gaps with plausible stories, and that is exactly where an explicit unknown state is required.
