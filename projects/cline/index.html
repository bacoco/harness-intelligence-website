Le constat reste au passe.Les instructions au niveau prompt ou règle ne sont pas appliquées de façon déterministe.At first, the chef gave an instruction and hoped it would be followed. Une porte tient mieux qu’un rappelMécanismeA door holds better than a reminderMechanism

Une phrase se perd dans le bruit. Une porte ouvre ou reste fermée. Mais dès qu’elle garde un geste important, il faut savoir ce que fait la brigade si elle se brise.Une instruction au niveau prompt n’a pas d’application déterministe : le flux a besoin d’une interception runtime à la frontière de cycle de vie concernée. Mais un hook qui garde la compaction n’est plus une liste de rappels : le harnais doit exposer exactement quel contexte lui est disponible, s’il peut annuler ou modifier, et ce qui se produit quand le hook lui-même échoue. Le même déplacement se lit ailleurs : une primitive décrite comme un ajout pouvait remplacer silencieusement un fichier existant parce que son contrôle de sécurité consultait un état incomplet au lieu d’interroger la destination à la frontière destructive.A sentence gets lost in the noise. A door opens or stays shut. Once it guards an important move, the brigade must know what happens when it breaks.A prompt-level instruction has no deterministic enforcement: the workflow needs runtime interception at the relevant lifecycle boundary. But a hook that guards compaction is no longer a callback list: the harness must expose exactly what context it sees, whether it can cancel or modify, and what happens when the hook itself fails. The same displacement shows elsewhere: a primitive described as an add could silently replace an existing file because its safety check consulted incomplete state instead of interrogating the destination at the destructive boundary.

Garder le grand carnet hors des raturesRéponseKeep the main book free of crossings-outResponse

Place une règle indispensable près du geste qu’elle retient. Garde le grand carnet intact. Les petites versions peuvent être refaites, mais elles ne doivent jamais être le seul souvenir du service.Quand une règle doit toujours tenir, la déplacer du conseil au niveau prompt vers une porte runtime à la frontière de cycle de vie concernée. Traiter chaque hook comme un contrôle doté de sémantiques d’échec déclarées, et non comme un simple point d’extension. Persister l’historique de conversation canonique indépendamment des skills, des résumés et des projections de compaction ; le contexte dérivé doit rester jetable et re-dérivable.Put an essential rule beside the move it holds back. Keep the main book whole. Short versions may be remade, but they must never be the service’s only memory.When a rule must always hold, move it from prompt-level advice to a runtime gate at the relevant lifecycle boundary. Treat every hook as a control with declared failure semantics, not merely an extension point. Persist canonical conversation history independently of skills, summaries and compaction projections; derived context must stay disposable and re-derivable.

Les portes sont posées, pas encore vues en salleÉtat actuelThe doors are hung, not yet seen in serviceCurrent state

Les portes sont posées et les trois carnets séparés. Elles n’ont pas encore été vues pendant un vrai service. L’ordre exact des derniers ajouts reste aussi incomplet.Le premier ensemble de hooks et l’extension de compaction sont intégrés, de même que les deux changements d’architecture séparant état source de vérité et contexte dérivé. Le schéma courant est plus riche que l’ensemble minimal intégré en 2025 ; la chronologie exacte des ajouts d’événements ultérieurs reste incomplète. La corrélation avec une version publiée et un runtime installé n’est pas faite. Un changement annoncé en notes de version reste une revendication, pas une validation terrain.The doors are fitted and the three books are separate. They have not yet been seen during real service. The exact order of the latest additions also remains incomplete.The first hook set and the compaction extension are merged, as are both architecture changes separating source-of-truth state from derived context. The current schema is richer than the minimal set merged in 2025; the exact chronology of later event additions is still incomplete. La règle doit vivre dans le gesteLeçonThe rule must live in the moveLesson

Une règle répétée peut s’oublier. Si elle est indispensable, la porte doit la porter. Une nouveauté annoncée reste une promesse tant qu’elle n’a pas tenu en plein service.Une règle qui doit toujours tenir appartient à une porte runtime, pas à un conseil de prompt. Une note de version est un delta de plan de contrôle de premier rang, mais la revendication ne se confond pas avec une validation terrain.A repeated rule can be forgotten. If it is essential, the door must carry it. An announced change remains a promise until it has held through service.A rule that must always hold belongs in a runtime gate, not in prompt advice. A release note is a first-class control-plane delta, but the claim is not the same thing as field validation.
