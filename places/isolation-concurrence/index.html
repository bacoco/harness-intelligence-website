Au passe, une seule ardoise sert à noter la table et le plat en cours. Seul, chaque cuisinier retrouve toujours sa ligne. Dès qu’ils écrivent à deux, leurs notes se croisent. Une assiette part alors à la mauvaise table.Un contrôle conservait, pour chaque exécution, les conditions d’environnement et les données du problème dans des champs ordinaires d’une instance unique. Sous exécution parallèle, deux exécutions partageaient cette instance et pouvaient s’écraser mutuellement. Des sorties ont pu être enregistrées sous le mauvais dossier de problème.One slate at the pass records the table and dish being prepared. Alone, each cook always finds his own line. With two writers, their notes cross. A plate then leaves for the wrong table.A check stored per-run environment conditions and problem data in ordinary fields on a single shared instance. Once runs overlapped, two of them shared that instance and could overwrite each other’s values. Outputs could be recorded against the wrong problem directory.

Une consigne de dépannage reste punaisée après la fin du service. Elle dit « la réserve du fond » sans nommer la maison. Le lendemain, dans une autre cuisine, ces mots désignent une autre réserve. Ils limitent une brigade qui n’avait rien demandé.gstack conservait dans un état global à la machine la frontière d’édition d’un mode de débogage, exprimée en chemin relatif et jamais effacée. Résolue plus tard depuis un autre répertoire de travail, cette même valeur désignait une autre zone et contraignait des sessions sans lien avec celle qui l’avait posée.A repair note remains pinned after closing time. It names a back shelf but not the kitchen it belongs to. During the next service, those words point elsewhere. They restrict a brigade that never asked for the note.gstack kept a debugging mode’s edit boundary in machine-global state, expressed as a relative path and never cleared. Resolved later from a different working directory, that single stored value designated a different area and constrained sessions unrelated to the one that set it.

Elles n’ont pas toutes achevé ce changement.Les worktrees et mécanismes équivalents d’isolation passent de discipline développeur à infrastructure gérée par le runtime, à mesure que l’exécution parallèle devient normale. Le plat de la première table part vers la suivanteUn état de connexion global et mutable pouvait faire livrer un message à la mauvaise sessionThe first table’s plate can reach the next partyShared mutable connection state could deliver a message to the wrong session

Une seule fiche sur le comptoir indique la table servie. Chaque nouvelle arrivée remplace cette fiche par la sienne. Le commis ne la lit qu’au départ de l’assiette. Le plat de la première table peut donc partir vers la suivante.Un état de connexion partagé et mutable permettait à une session ultérieure de remplacer la connexion globalement courante. Une notification émise ensuite pour la première session pouvait donc emprunter la connexion d’une autre.One card on the counter names the table being served. Every new party replaces it with another card. The runner reads it only when leaving the pass. A plate ordered by the first table can therefore reach the next one.Shared mutable connection state let a later session replace the globally current connection. A notification raised afterwards for the first session could then ride another session’s connection.

Plusieurs commis se disputent le même billotL’allocation de worktrees est entrée dans le chemin d’exécution, à titre expérimentalSeveral cooks collide on one shared benchWorktree allocation entered the execution path, as an experimental feature

Avec un seul commis, le billot commun ne gêne personne. À plusieurs, les préparations commencent à se mélanger. La maison essaie donc un billot par commis. Cette organisation n’est pas encore utilisée partout.L’allocation gérée de worktrees est entrée dans le chemin d’exécution des sessions CLI. L’isolation du workspace devient ainsi une capacité de première classe du harnais plutôt qu’une convention appliquée par l’utilisateur. La fonctionnalité est explicitement expérimentale ; rien n’établit qu’elle soit devenue le comportement par défaut.One cook has no trouble with a shared bench. With several cooks, preparations begin to collide. The house is therefore trying one bench per cook. Not every service uses it yet.Managed worktree allocation moved into the execution path of CLI sessions. Workspace isolation thereby becomes a harness capability rather than a convention users are expected to apply themselves. The feature is explicitly experimental, and nothing establishes it as the default.
